# کافه ژیپسوفیلا

یک وب‌سایت استاتیک فارسی برای مرور منو و آماده‌کردن سبد خرید. پروژه بدون فریم‌ورک و مرحله‌ی build اجرا می‌شود.

جهت بصری سایت بر پایه‌ی تایپوگرافی فارسی تحریری، عکس‌های کم‌اشباع و رنگ‌های زغالی و شرابی است. فونت‌های Noto Naskh Arabic، Vazirmatn و Playfair Display فقط با وزن‌های استفاده‌شده بارگذاری می‌شوند؛ نمادهای رابط نیز در ابتدای `index.html` تعریف شده‌اند.

## ساختار

- `index.html` — ساختار صفحه.
- `style.css` — رنگ‌بندی، چیدمان، واکنش‌گرایی و انیمیشن‌های سایت.
- `script.js` — تنظیمات شعبه‌ها، داده‌های منو و تعاملات صفحه.

## اجرای محلی

پروژه را با یک وب‌سرور استاتیک محلی اجرا کنید؛ فایل را مستقیم با `file://` باز نکنید تا `script.js` به‌درستی بارگذاری شود.

## تنظیم برای استفاده‌ی واقعی

- ویرایش شعبه‌ها و نوشیدنی‌ها در ابتدای `script.js` انجام می‌شود.
- نام‌ها و نشانی‌های فعلی شعبه‌ها نمایشی و خیالی هستند؛ پیش از انتشار اطلاعات واقعی را جایگزین کنید.
- سفارش واتساپی عمداً تا زمان ثبت شماره‌ی رسمی بین‌المللی برای هر شعبه غیرفعال است. مقدار `whatsapp` را فقط با شماره‌ی متعلق به همان شعبه تنظیم کنید.
- فرم تماس، ساعات کاری، شبکه‌های اجتماعی و مسیریابی تا زمان اضافه‌شدن اطلاعات معتبر فعال نیستند.
- قیمت‌ها در `script.js` نگهداری می‌شوند و برچسب قیمت فعلی «ریال» است.

این پروژه در حال حاضر backend، پرداخت آنلاین یا قابلیت هوش مصنوعی ندارد؛ سبد خرید در مرورگر ساخته می‌شود و به سرور ارسال نمی‌شود.
